# Python Programming Internship

## Overview
This repository contains the programs and mini-project completed as part of my Python Programming Internship.

## Basic Python Programs

The `basic_programs` folder contains the following Python programs:

- `hello_world.py` – Hello World program
- `variables.py` – Variables demonstration
- `data_types.py` – Data types demonstration
- `user_input.py` – User input and output
- `calculator.py` – Basic arithmetic operations
- `temperature_converter.py` – Celsius to Fahrenheit conversion
- `simple_interest.py` – Simple interest calculation
- `conditions.py` – Conditional statements
- `loops.py` – For loop demonstration
- `functions.py` – Functions demonstration
- `modules.py` – Python modules demonstration

## Mini Project: Personal Expense Tracker

The Personal Expense Tracker is a command-line application developed using Python.

### Features
- Add expenses
- View recorded expenses
- Calculate total expenditure
- Input validation
- Exit the application

### Technologies Used
- Python 3.12
- Visual Studio Code
- Git and GitHub
